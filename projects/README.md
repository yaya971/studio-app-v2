# projects/

Ce dossier contient tous les projets créés dans Studio A V2.

Chaque projet est un sous-dossier autonome avec sa propre structure et son README.

## Créer un nouveau projet

Il suffit de demander à Antigravity dans le chat, par exemple :

- "Crée-moi une landing page pour mon SaaS de musique"
- "Construis une app de gestion de tâches avec auth"
- "Fais-moi un dashboard analytics en temps réel"

L'agent s'occupe de tout : structure, code, design, tests, push GitHub.
