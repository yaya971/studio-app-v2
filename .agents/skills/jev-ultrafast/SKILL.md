# ⚡ Jev Ultrafast — Sub-10s Browser Automation Agent

Located in `tools/jev-ultrafast/`.

## Capabilities
- **Sub-10 Second Multi-Step Task Execution**: Drastically faster than traditional playwright/puppeteer agent scripts using optimized element pruning.
- **Dynamic DOM Indexing**: Fast visual element tagging that enables direct coordinate and DOM path clicking without full-page re-scanning.
- **Form Filling & Workflow Automation**: Automates complex logins, multi-page surveys, portal submissions, and flight/ticket searches.
- **Stealth & Headless Mode**: Runs cleanly headlessly or with browser UI for visual verification.
